# Personal Linux Development Tools

This repository contains a collection of development tools and environment for
machines running Linux.


## Installation

### x86 (Ubuntu 26.04)

Ubuntu 26.04 on x86_64 is required to run the installation script. It installs
Oh My Zsh, Node.js 24, Bun, Neovim 0.11, tmux, and common development tools.

```bash
bash <(curl -sL https://raw.githubusercontent.com/nicomiguelino/devtools/main/scripts/x86/ubuntu/26.04/install.sh)
```

### Raspberry Pi OS Lite (Bookworm/Debian 12)

Debian 12 (Bookworm) and later is required to run the installation script.

```bash
bash <(curl -sL https://raw.githubusercontent.com/nicomiguelino/devtools/main/scripts/raspberrypi/install.sh)
```

### x86 (Debian 12 Bookworm)

Debian 12 (Bookworm) and later is required to run the installation script.

```bash
bash <(curl -sL https://raw.githubusercontent.com/nicomiguelino/devtools/main/scripts/x86/debian/12/install.sh)
```
